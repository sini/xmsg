Start with one user's local xmsg daemon and your agent harnesses. Add federation when a recipient
runs on another node; use a bridge or gateway for an external chat or hosted client.

## Connect your harness

Choose [Claude Code](/harnesses/claude-code/), [Codex](/harnesses/codex/),
[Antigravity](/harnesses/antigravity/), [opencode](/harnesses/opencode/),
[Pi](/harnesses/pi/) or [Hermes](/harnesses/hermes/). Their registration and delivery mechanisms
differ; each guide gives the supported setup. Use `list` to discover a recipient, `send` to start
an exchange, and `reply` with the received message ID to answer.
