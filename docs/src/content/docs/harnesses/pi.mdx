`xmsg` ships a TypeScript extension (`extensions/pi/index.ts`) for the Pi coding agent
(`@earendil-works/pi-coding-agent`).

## How the Pi extension works

- **Registration & long-poll:** At startup, the extension connects to
  `$XDG_RUNTIME_DIR/xmsg/register.sock`. `xmsg serve` checks the peer UID (`SO_PEERCRED` /
  `getpeereid`). It records the process start time and makes a new UUID v4 for the session. The
  session's display label is its Pi session name. If it has no name, the label is the basename of
  its working directory.
- **Safe prompt injection:** Incoming messages arrive over the `register.sock` long-poll loop
  (`poll` $\rightarrow$ `ack`). xmsg delivers them into Pi with `expandPromptTemplates: false`.
  This prevents remote command expansion and prompt-template expansion.
- **Tools (`list`, `send`, `reply`, `replies`):**
  - `list`: Asks for active recipients over `$XDG_RUNTIME_DIR/xmsg/http.sock`, or over
    `XMSG_URL` when you set it.
  - `send`: Sends messages over `$XDG_RUNTIME_DIR/xmsg/agent.sock`, with kernel PID attestation.
  - `reply`: Sends replies over `$XDG_RUNTIME_DIR/xmsg/agent.sock`.
  - `replies`: Reads the stored replies to a sent message over `agent.sock`. It waits up to `wait`
    seconds (at most 60) for the first reply.
- **Socket paths:** `XMSG_REGISTER_SOCK`, `XMSG_AGENT_SOCK` and `XMSG_HTTP_SOCK` override the
  defaults. On macOS without `XDG_RUNTIME_DIR`, the runtime directory is the Darwin user temporary
  directory, as for `xmsg serve`.
- **Lifecycle:** A Pi session's UUID is bound to its process. Thus when Pi exits, xmsg releases
  the session. Later sends to its UUID return `410 gone`. A Pi session is never `parked`. Pi is a
  single-session process. It does not use subagent sub-addresses or `inbox`.

## Home Manager switch

In Home Manager, set `programs.xmsg.harnesses.pi.enable = true`. This installs
`~/.pi/agent/extensions/xmsg-pi.ts` and `~/.pi/agent/skills/xmsg/SKILL.md`. Pi automatically
loads all extensions under `~/.pi/agent/extensions/`. See
[NixOS & Home Manager](/operations/nixos-and-home-manager/#per-harness-switches).
