`flake.nix` builds an unprivileged, distroless OCI container image with
`pkgs.dockerTools.buildLayeredImage`. The image is published to `ghcr.io/sini/xmsg`:

```nix file=<rootDir>/flake.nix#L80-L100
```

## Security properties

- **Non-root execution:** Runs as UID/GID `10001:10001`.
- **No shell or utilities:** The image contains only CA certificates
  (`/etc/ssl/certs/ca-bundle.crt`) and the `xmsg` binary. No layer has `/bin/sh` or other tools.
- **Entrypoint:** `xmsg` with default command `serve` and working directory `/var/lib/xmsg`.

## Building & verification

```bash
# Build the OCI image archive
nix build .#image

# Run the image oracle check (asserts non-root user, xmsg entrypoint, and no /bin/sh in layers)
nix build -L .#checks.x86_64-linux.image
```
