# Implementation Spec: Dispatch U9.1 — Identity & Verification Repairs

- **Date:** 2026-10-07
- **Target:** `xmsg`
- **Reference Gate Report:** `reports/xmsg-u9-gate.md` (Gate rejection of U9 at `bfe6c80`)
- **Owner Ruling on macOS Fork (G1):** "C -> B". Option C investigated: macOS kernel (`libproc`, `sysctl`, `fcntl(F_GETLK)`) does not expose `flock(2)` holders or lock state to unprivileged userspace. Therefore, Option C cannot distinguish a real session from an inherited descriptor. Option B is chosen: macOS accepts the (a)+(b) proof, and the gap is documented plainly in `README.md`.

---

## 1. Problem & Scope

The independent gate at `bfe6c80` identified two major construction defects (G1, G2), one major policy defect (G3), and four minor issues.

### 1.1 G1 (Major Construction) — Inherited Presence File Bypass & Store Collision
- **Linux FLOCK bypass:** `verify_registration` in `src/agy.rs:543` accepted `Ok(None)` from `find_lock_holder`. If a process inherits an open fd to the presence file without locking it, and no FLOCK line exists in `/proc/locks` for the inode, registration succeeded.
- **Store Key Collision:** `run_register_server` inserted registrations twice: under `reg.session_key` (`agy:<pid>:<starttime>`) and under `req.conversation_id`. The latest registration overwrote the second key, allowing spoofed badge names and conflicting sessions.

### 1.2 G2 (Major Construction) — Unattested Caller attestation on `agent.sock`
- `src/agent.rs` (`resolve_caller_session` lines 164-199) checked `/proc/locks` directly for presence file holders and returned them as `harness: "agy"` with `session_id = <stem>`. This bypassed the U9 proof (a)+(b) entirely and accepted any process holding a FLOCK without checking its executable.
- `src/agy.rs` retained `find_ancestor_agy_session_in`, a dead lock-only walker.

### 1.3 G3 (Major Policy) — Pi Process Verification Gaps
- `src/pi.rs` (`verify_pi_process`):
  1. Only checked if executable file name was `node` or `nodejs`, accepting any binary named `node`.
  2. Skipped flags using `skip(1).find(|arg| !arg.starts_with('-'))`, allowing leading flags like `--require=...` or `--import=...`.
  3. Canonicalized relative script arguments against the server's CWD instead of `/proc/<pid>/cwd`.

### 1.4 Minors
1. **Starttime read race:** Starttime was read after the ancestor walk. If the PID exited and was recycled during the check, the key could pin the new process.
2. **Liveness empty starttime:** `is_agy_session_alive` returned `true` when `starttime` was empty.
3. **`exe_path` fallback:** Fallback `Err(_) if exe_link.is_file() => Ok(exe_link)` ran on live Linux roots (`/proc`).
4. **Docs:** `README.md` must clearly document Pi verification as a misconfiguration guard (not an identity proof), document the macOS Option B gap, and note that `(deleted)` exes and profile upgrades fail closed.

## 2. Technical Mechanism

### 2.1 G1: Linux FLOCK Enforcement & Single Store Key
- In `src/agy.rs:verify_registration`:
  ```rust
  if locks_supported(proc_locks) {
      let maj = dev_major(target_dev);
      let min = dev_minor(target_dev);
      match find_lock_holder(proc_locks, maj, min, target_ino) {
          Ok(Some(flock_holder)) => {
              if flock_holder != chosen_pid {
                  return Err(AppError::NotRecipient(format!(
                      "FLOCK holder PID {flock_holder} does not match chosen ancestor PID {chosen_pid}"
                  )));
              }
          }
          Ok(None) => {
              return Err(AppError::NotRecipient(format!(
                  "presence lock file has no FLOCK holder in {proc_locks:?}"
              )));
          }
          Err(e) => {
              return Err(AppError::Ambiguous(format!(
                  "ambiguous presence lock in /proc/locks: {e}"
              )));
          }
      }
  }
  ```
- In `src/agy.rs:run_register_server`:
  Key `AgyStore` exclusively on `reg.session_key`. Remove `store_lock.insert(req.conversation_id.clone(), session_info)`.
- In `src/agy.rs:deliver_agy_envelope`:
  Lookup `session_info` primarily by `session.session_id` (`agy:<pid>:<starttime>`), with fallback iterating `store_lock.values()` matching `info.conversation_id == session.session_id || session.name.as_deref() == Some(&info.conversation_id)`.

### 2.2 G2: Remove Lock-Only Attestation & Dead Walker
- In `src/agent.rs:resolve_caller_session`:
  Remove lines 164-199 (the `/proc/locks` presence lock check). Callers are attested as `agy` exclusively if they match a live entry in `AgyStore` (`pid > 0`, `pid == curr_pid`, `is_agy_session_alive`).
- In `src/agy.rs`:
  Remove `find_ancestor_agy_session_in`.

### 2.3 G3: Tightened Pi Process Verification
- In `src/process.rs`:
  Add `pub fn cwd(proc_root: &Path, pid: u32) -> io::Result<PathBuf>`:
  - On Linux live `/proc`: `fs::read_link(proc_root.join(pid.to_string()).join("cwd"))`.
  - On macOS live: query `proc_pidvnodepathinfo` (`pvi_cdir.vip_path`).
  - On synthetic fixture: read link or file content if `proc_root != Path::new(LIVE_PROC_ROOT)`.
- In `src/pi.rs:verify_pi_process`:
  - Accept `trusted_node_bins: &[PathBuf]`. If not empty, canonicalize `exe` and verify it matches a canonical path in `trusted_node_bins`. If empty, verify `exe_name == "node" || exe_name == "nodejs"`.
  - Check script argument: `args.get(1)` must exist and must NOT start with `-`. If `args.get(1)` starts with `-`, return `AppError::BadRequest("peer process has flag before script argument")`.
  - Resolve relative script paths: if `script_arg` is relative, resolve it via `proc_cwd.join(script_arg)` where `proc_cwd = process::cwd(proc_root, peer_pid)` before canonicalizing.
- In `src/main.rs`:
  Add `--pi-node-bin <PATH>` (`XMSG_PI_NODE_BIN`) CLI flag, passed to `verify_pi_process` and `handle_pi_connection`.

### 2.4 Minors
- **Minor 1 (Starttime race):** In `src/agy.rs:verify_registration`, read `st1` before/during ancestor inspection, re-read `st2` after lock verification. If `st1 != st2`, return `AppError::Internal("process recycled during verification")`.
- **Minor 2 (Empty starttime):** In `src/agy.rs:is_agy_session_alive`, return `false` if `info.starttime.is_empty()`. Move `impl From<AgyCredentials> for AgySessionInfo` into `#[cfg(test)]`.
- **Minor 3 (`exe_path` fallback):** In `src/process.rs:exe_path`, restrict `Err(_) if exe_link.is_file() => Ok(exe_link)` with condition `proc_root != Path::new(LIVE_PROC_ROOT)`.
- **Minor 4 & Documentation:** Update `README.md` and `docs/probes/macos-agy.md` describing macOS Option B gap, Pi misconfiguration guard role, and fail-closed behavior on deleted binaries and profile upgrades.

## 3. Acceptance Oracles & Verification

Create dedicated test suite `tests/gate_u9_1_repairs.rs` containing cells for every finding:
1. `cell_g1_linux_refuses_when_no_flock_holder`: Inherited fd without FLOCK in `/proc/locks` is rejected.
2. `cell_g1_store_keyed_on_session_key_only`: `AgyStore` contains only `session_key`; direct query on `conversation_id` returns `None`.
3. `cell_g2_agent_sock_refuses_unregistered_lock_holder`: `resolve_caller_session` returns `NotRecipient` for an unregistered FLOCK holder.
4. `cell_g3_pi_refuses_leading_flags`: `node --require=evil.js /path/to/cli.js` returns `BadRequest`.
5. `cell_g3_pi_resolves_relative_script_against_proc_cwd`: Relative script `./dist/cli.js` resolves using `/proc/<pid>/cwd`.
6. `cell_g3_pi_node_bin_verification`: Configured node binary rejects untrusted binary even if named `node`.
7. `cell_minor_1_starttime_race_detected`: PID recycling during registration fails verification.
8. `cell_minor_2_empty_starttime_not_alive`: `is_agy_session_alive` returns `false` on empty starttime.
9. `cell_minor_3_live_exe_no_file_fallback`: Live proc root does not fall back to `is_file()`.
